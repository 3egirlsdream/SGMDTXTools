# 三国：谋定天下 - 游戏总览

> 最后更新: 2026-04-17 | 置信度: 高 | 来源: 截图分析/网络资料/官网

## 概述

《三国：谋定天下》（简称"三谋"）是一款三国题材SLG(策略类)手游，由B站(哔哩哔哩)发行，是首款多职业战争策略手游。玩家扮演一方诸侯，通过建设城池、招募武将、训练军队、攻城略地，最终与盟友一统天下。游戏以公平策略为核心，不靠数值碾压，而靠谋略确定胜负。

## 核心玩法

### 大地图策略
- 基于网格的大地图，每个格子有等级(1-12级)
- 玩家需要占领地块(领地)来获取资源和繁荣度
- 通过道路连接领地形成领土网络
- 地图按州/郡/县划分区域，如"冀州-常山郡-邯郸"
- 1-9级地块在出生州，10-11级在资源州(雍州/豫州等)，12级在中央区域

### 城池建设
- 内城建筑提供各种功能加成，建造瞬间完成
- 核心建筑：君王殿(决定城池等级、解锁建筑和科技)
- 建筑分类：资源建筑、军事建筑、功能建筑

### 武将与战斗
- 收集三国武将，配置3人一队
- 武将品质：橙色(最高) > 紫色 > 蓝色
- 武将有战法(技能)系统，战法品质与武将品质对应
- 武将等级上限50级，等级可免费置换转移
- 战法可免费重置(新手期)

### 联盟/国家
- 玩家加入国家(同盟)，协作攻防
- 国家标识显示在玩家名称前，如[漢]、[楚]等
- 玩家名格式: `职业简称|同盟名|角色名`，如 `工|千里|张三丰`、`青|漢|不带书`
- 职业简称: 工(天工)、司(司仓)、镇(镇军)、青(青囊)、神(神行)、奇(奇佐)
- 同盟基础是城池，城池产出辎重和精铁
- 辎重用于非主城快速征兵，精铁是建造大营的材料

## 六大职业

游戏特色的职业系统，本质是社会分工：

| 职业 | 定位 | 核心能力 | 适合人群 |
|------|------|----------|----------|
| **司仓** | 后勤物资 | 军屯(帮盟友获取资源)、五谷丰登(额外资源)、生产辎重 | 休闲玩家、开荒最强之一 |
| **镇军** | 战斗专精 | 势如破竹等战斗增益，正面硬刚 | 喜欢战斗的玩家(需要红度) |
| **青囊** | 医疗支援 | 自制体力药(每天多60点体力)、治疗支援 | 喜欢发育、开荒强 |
| **神行** | 机动穿梭 | 行军速度加成、灵活穿梭战场 | 喜欢机动打击 |
| **天工** | 工程建设 | 抛石机、箭塔建造、团队建设 | 喜欢功能性玩法(肝度高) |
| **奇佐** | 战术策划 | 策书回复加速、战术指挥 | 喜欢功能性玩法(肝度高) |

**职业推荐**：
- 想战斗爽：司仓、青囊、镇军
- 想玩机制：天工、奇佐、神行
- 开荒最强：司仓、青囊(司仓略胜)

## 关键数值

### 繁荣度
- 体现玩家实力的核心指标
- 提升方式：攻占城外资源地、开垦内城资源地、提升内城建筑等级、提升研究所科技等级
- 用于完成主线任务和活动排名(影响金铢奖励)

### 领地与道路
- 领地：有上限(如60/60, 65/65)，提供资源产量和繁荣度
- 道路：有上限(如16/16, 35/35)，不提供产量和繁荣度，用于连接领地
- 上限随发展提升

### 策书
- 每30分钟回复一点
- 用于屯田获取资源
- 奇佐职业可通过天赋加速回复
- 不要让策书满，要及时使用

### 体力
- 武将行动(打地/扫荡/校练)消耗体力
- 体力上限: 200
- 20体力：100%经验
- 10体力：80%经验
- 0体力：不能获得经验
- 青囊每天多60点体力
- 鸡腿(体力恢复道具)通过主线任务获取
- **讨伐西凉游兵不消耗体力**

### 货币体系
- **金铢**：高级货币(充值/活动获取)，用于武将置换、加速等
- **求贤令**：寻访(抽卡)专用货币
- **铜币**：通过民居产出/寻访获得，用于战法升级、装备打造、韬略

## 赛季制

- 游戏采用赛季制(S1/S2/S3...)
- **当前玩家赛季: S13**（问鼎赛季，剧本"兴汉讨逆"）
- 赛季结算后进入新赛季，多服务器合并匹配
- **保留项**：武将、战法、部分装备(赛季仓库可带入4件装备和坐骑)
- **重置项**：主线任务进度、霸业进度、领地、建筑等级、资源
- 新赛季带入装备后无法养成(淬炼、点化、繁育等)
- 霸业：赛季最终目标，根据同盟积分排名和占领州府获得
- **S13转职限制**：本赛季只能转职1次，需谨慎选择

### S13赛季特色（兴汉讨逆）

#### 讨伐董卓（全服PvE）
- 地图中心京畿区域默认由NPC董卓占领
- 京畿区域含690个12级资源地(木/铁/石/粮)
- 三方阵营需协作讨伐董卓
- 董卓会在资源州和京畿部署专属部队，并发布檄文
- 讨伐成功条件：董卓最终占城<5个且无焚毁城池

#### 烽烟纪略（进度追踪系统）
- 随霸业进程解锁剧情章节和奖励
- 按章节给予不同奖励
- 逐步解锁各种个人能力（共9项）

#### 霸业规则（S13大改）
- **问鼎**: 胜方前220人 + 官员获得问鼎名额
- **霸业**: 总计260个名额，分4类:
  1. 讨伐董卓成功: 每方10人(共20) — 需董卓占城<5且无焚毁
  2. 第二名势力: 自动获得50个名额
  3. 宫殿控制: 占领云台/德阳各50(共100)
  4. 州府据点: 资源州中心各10 + 出生州中心各5(共90)

#### 衍义战法系统（S13新增）
- 6个衍义战法，但只有4个衍义格子（需取舍）:

| 衍义战法 | 原战法 | 路线特点 |
|---------|--------|---------|
| **辕门射戟** | 辕门射戟 | 输出路线(降低10%发动率但提高兵刃倍率+追击伤害15%) / 辅助路线 |
| **轻装驰援** | 轻装驰援 | 指挥路线(自动施加兵力最低2人+抵御) / 连击辅助路线(友军+10%连击率+增伤) |
| **斩将夺旗** | 斩将夺旗 | 两条路线 |
| **王佐之才** | 王佐之才 | 两条路线，补强魏延体系 |
| **清风驱疾** | 清风驱疾 | 两条路线 |
| **任人择势** | 任人择势 | 两条路线 |

#### 藏品韬略/藏书阁系统
- 霸业进程达到"势如破竹"解锁藏书阁
- S13赛季4个藏品韬略:

| 藏品韬略 | 效果概述 |
|---------|---------|
| **吕布** | 增伤 + 回血 + 额外普攻 |
| **张飞** | 稳定控制 + 震慑概率提升至30%，补强魏延体系(墩飞延/泰飞延) |
| **夏侯惇** | 横征暴敛 + 固若金汤，催生惇曹异T0阵容 |
| **田丰** | 强化搭配 |

#### S13新武将
- **群·孙坚**: 群雄主动兵刃后排核心，定向锁后排(统御最低单体)，叠层后无视虚弱/防御的逃兵真伤，克制雁形阵。推荐搭配: 左慈/田丰、孙权/陆抗、皇甫嵩/袁术
- **木鹿大王**: 南蛮体系核心，三南蛮缘分开局18%全队全回合减伤。绑定孟获+祝融夫人，可替代SP诸葛亮
- **签到奖励**: 太史慈

#### S13新战法
- **恩威并施**: 针对薪火枪的定向战法
- **未雨绸缪**: 与指挥型武将机制关联

## 新手期

- 有免战保护和占地时间减半
- 武将置换免费、战法重置免费
- 新手期结束后，每周武将置换超出次数会消耗黄金
- 新手期应尽可能多占高级资源地
