# 领地系统

> 最后更新: 2026-04-17 | 置信度: 高 | 来源: 截图分析/网络资料/官网

## 概述

大地图由网格组成，每个格子是一个地块。玩家通过占领地块扩展领地，连接道路形成领土网络。领地提供资源产量和繁荣度，道路仅用于连接。

## 地块等级

- 地块共分12个等级
- **1-9级**：分布在各出生州
- **10-11级**：分布在资源州（雍州、豫州等）
- **12级**：分布在中央区域
- 等级显示在地块角落（数字标注）
- 高等级地块提供更多资源产出
- 占领高级地块需要更强的兵力
- **土地开发**：城外高级地被占满后，可利用土地开发功能提升低级地的等级和产量

### 资源地产量参考（截图实测）

| 地块等级 | 每小时产量 | 来源 |
|---------|-----------|------|
| 10级 | ~3400/小时 | 城池面板 |
| 11级 | ~3700/小时 | 城池面板（粮食等级11级） |

> 注：以上产量为城池面板中观察到的单项资源产出，实际可能受建筑加成影响

## 地图区域划分

游戏地图按 **州 → 郡 → 县** 三级划分：

### S13地图结构
- **出生州**: 各阵营起始区域，含1-9级地块
- **资源州**: 雍州、豫州等，含10-11级地块
- **京畿区域(S13核心)**: 地图中心，默认由NPC董卓占领
  - 含**690个12级资源地**(木/铁/石/粮)
  - 是三方争夺的核心战略要地
  - 讨伐董卓后可获取大量高级资源地
  - 含**云台**和**德阳**两个关键宫殿据点(各值50霸业名额)
- 战场维持**三方阵营对抗**格局（南北划分）

## 领地与道路

### 领地
- 有上限（如 60/60、65/65）
- **提供资源产量和繁荣度**
- 占领地块计入领地数量
- 上限随发展提升

### 道路
- 有上限（如 6/35、16/16、35/35）
- **不提供资源产量和繁荣度**
- 用于连接玩家占领的领地
- 方便部队移动和盟友支援

### 自动转换规则（重要！）
1. **领地名额未满时**：新夺取地块直接划为领地
2. **领地已满、道路未满时**：
   - 若新地块等级 > 现有最低等级领地 → 最低等级领地自动变为道路，新地块变为领地
   - 若新地块等级 ≤ 最低等级领地 → 新地块直接作为道路
3. **两项都满时**：系统优先弃置存在时间最长的道路，然后按上述规则判定
4. **领地配额扩容后**：道路不会自动转化为领地（需手动处理）

### 策略建议
- 扩张应优先抢占高级地块
- 领地满后新占地会自动触发转换，注意低级领地可能变道路
- 配额扩容后需手动调整

## 地块颜色

- **绿色**：己方/友方领地
- **蓝色**：己方控制区域
- **橙色/红色**：敌方领地
- **无色**：中立/未占领

## 县城系统（截图实测）

县城是大地图上介于普通资源地和大城池之间的据点：

| 属性 | 说明 |
|------|------|
| **示例** | 平皋 Lv.11 |
| **守军** | NPC守军驻守，需击败占领 |
| **产出** | 资源产出 |
| **霸业积分** | 占领县城可获得霸业积分 |
| **面板信息** | 显示守军兵力、资源产出、霸业积分 |

### 霸业积分
- 通过占领县城和参与赛季目标获得
- 与赛季排名和最终奖励相关
- 是同盟间竞争的核心指标之一

## 关口

- 截图中观察到"关口"标记（16级关口）
- 关口是连接区域的关键地点
- 关口战是赛季中的重要战略目标

## 繁荣度来源（领地相关）

- 成功攻占城外资源地可增加繁荣度
- 地块等级越高，提供的繁荣度越多
- 满级资源地最高可提供30繁荣度
