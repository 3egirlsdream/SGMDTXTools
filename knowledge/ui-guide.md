# UI操作指南

> 最后更新: 2026-04-17 | 置信度: 高 | 来源: 截图分析/网络资料

## 概述

游戏UI为竖屏布局(约9:16比例)，主要分为顶部信息栏、中间地图区、底部功能栏三大区域。

## 屏幕布局

```
┌─────────────────────────────┐
│  [延迟] [资源栏:粮/木/铁/石]│  ← 顶部：左上延迟，中间资源
│  繁荣 xxx  领地 xx/xx       │     繁荣/领地/道路/金铢
│  道路 xx/xx     [金] xxxx   │
├─────────────────────────────┤
│  [功能图标行]               │  ← 活动/赛季入口等快捷图标
│  [头像]                     │  ← 左上角主公头像
├─────────────────────────────┤
│                             │
│                             │
│      大 地 图 区 域          │  ← 中间：可拖动的战略地图
│      (可缩放/拖动)          │     显示城池/营帐/部队/地块
│                             │
│                             │
├─────────────────────────────┤
│  [定位] [消息]   [寻访]     │  ← 底部上方：定位/消息/寻访
│  [武将][国家][职业][征战]    │  ← 底部栏：4个主要功能入口
└─────────────────────────────┘
```

## 顶部信息栏

### 资源栏（从左到右）
1. 粮食：增量 + 当前/上限
2. 木材：增量 + 当前/上限
3. 铁矿：增量 + 当前/上限
4. 石料：增量 + 当前/上限

### 状态信息
- **繁荣**：左侧显示繁荣度数值（体现玩家实力）
- **领地**：如 65/65（当前/上限）
- **道路**：如 35/35（当前/上限）
- **金铢**：右侧显示，带"+"购买按钮

### 左上角
- 延迟(ms)显示：如 62ms、54ms、81ms
- 游戏时间：如 12:48:32

## 底部功能栏

### 主要入口（从左到右）
1. **武将** - 武将管理界面（查看/升级/换装备/战法）
2. **国家** / **同盟** - 联盟管理（同盟设施、军屯入口在此）
3. **职业** - 职业系统（职业天赋/技能升级）
4. **征战** - 战斗相关功能

### 底部上方
- **定位按钮**（左下角）- 定位到主城
- **消息图标** - 显示未读消息数(红色气泡)
- **寻访**（右下角）- 抽卡/招募武将（寻访台入口）

## 地图操作

### 点击空地
- 显示坐标信息（如"河北-魏郡-临水(502,1029)"）
- 显示地块等级
- 显示收藏/举报/分享按钮

### 点击营帐
弹出信息面板：
- 国家标签 + 营帐名称（如"营帐一"）
- 主公名称 + 信息按钮
- 调动数量：x/x
- 营帐HP条：当前/最大
- 操作按钮：**行军** / **驻守**

### 点击城池
弹出信息面板：
- 国家标签 + 城池名称
- 主公名称
- 守军兵力（如42000x2）
- 粮食产出（如3700/小时）
- 粮食等级（如11级粮食）
- 操作按钮：**筑城** / **行军** / **扫荡** / **驻守**

### 点击己方主城
- 进入内城界面
- 可查看和操作所有内城建筑
- 城建操作界面管理建筑

## 右侧武将栏

- 屏幕右侧显示当前部署的武将头像列表
- 最多显示约5-6个武将头像
- 是当前已出征/部署的部队
- 点击可查看部队详情

## 主城菜单覆盖层（截图实测）

进入主城后，点击特定按钮会弹出一个菜单覆盖层，包含以下功能入口：

| 按钮 | 功能 | 备注 |
|------|------|------|
| **结义** | 社交系统，结义好友 | - |
| **设置** | 游戏设置 | - |
| **城务** | 日常活动管理（6项活动） | **核心日常入口** |
| **外观** | 主城外观装扮 | - |
| **战法** | 战法管理/学习/传承 | - |
| **排行** | 各类排行榜 | - |
| **编队** | 部队编组管理 | - |
| **背包** | 道具物品管理 | - |

## 寻访界面（截图实测）

寻访（抽卡/gacha）界面详情：
- **入口**：右下角"寻访"按钮 或 内城寻访台
- **保底机制**：界面有保底计数器显示（如"距离保底还剩N次"）
- **抽卡类型**：武将寻访、战法寻访
- **消耗**：求贤令（单抽/十连）
- **产出**：橙色/紫色/蓝色武将或战法

## 内城界面

进入主城后的建筑操作界面：
- 可建造/升级各种内城建筑
- 开垦内城资源地
- 管理军事/资源/功能建筑
- 建造瞬间完成，无需等待

## 聊天系统

- 屏幕底部有聊天消息滚动显示
- 显示玩家名和消息内容
- 世界频道/国家频道

## 关键操作入口总结

| 操作 | 入口位置 |
|------|----------|
| 屯田 | 城务界面 → 屯田 / 点击内城资源地 → 屯田(余N)按钮 |
| 讨伐 | 城务界面 → 讨伐西凉游兵 |
| 军演 | 城务界面 → 军演 |
| 远征 | 城务界面 → 远征 |
| 拍卖 | 城务界面 → 拍卖（周二/四/六 18:00） |
| 开采军屯 | 城务界面 → 开采军屯 |
| 军屯(司仓) | 同盟界面 → 设施 |
| 城务总入口 | 主城菜单覆盖层 → 城务 |
| 寻访(抽卡) | 右下角"寻访"按钮 / 寻访台 |
| 集市(交易) | 内城集市建筑 |
| 装备打造 | 内城铁匠铺 |
| 马匹获取 | 内城马市 |
| 职业技能 | 底部"职业"按钮 |
| 研究科技 | 内城研究所 |
