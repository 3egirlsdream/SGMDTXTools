# 阵容搭配

> 最后更新: 2026-04-17 | 置信度: 高 | 来源: 截图分析/网络资料/官网

## 概述

每支部队由3名武将组成，合理搭配阵容是战斗胜负的关键。游戏提供免费武将置换和战法重置机制(新手期)，鼓励玩家反复尝试。部队由防御、输出、治疗三种角色构成，根据战法判断武将定位。

## S13赛季热门阵容（当前赛季）

> S13百花齐放，不存在完全无解的完美阵容，每支队伍都有其适配环境和优劣势。克制关系是选队核心。

### T0级阵容

#### 惇曹异（夏侯惇+曹操+王异）
- **定位**: S13新晋核心T0，由藏品夏侯惇催生
- **核心**: 藏品夏侯惇(横征暴敛+固若金汤) + 衍·任人择势 + 折冲御侮
- **覆盖面**: 覆盖战场多数目标
- **弱势**: 仅对左田孙等少数体系处于下风

#### 泰飞延（泰山+张飞+魏延）/ 墩飞延
- **定位**: T0级持久强队
- **核心**: 藏品张飞(震慑概率30%)补强魏延体系
- **变体**: 墩飞延(夏侯惇+张飞+魏延)
- **优势**: 覆盖惇曹异的短板区间
- **弱势**: 需避开高闪避与强治疗体系

#### 左田孙（左慈+田丰+孙坚/孙权）
- **定位**: 平民局核心反制单元
- **核心**: 群·孙坚定向锁后排真伤
- **优势**: 专门针对惇系阵容及法师体系
- **适合**: 中低红度玩家

### T1级阵容

#### 赵甘姜（赵云+甘夫人+姜维）
- **定位**: 利用规避特性反制热门组合
- **优势**: 反制周瑜、魏延等热门队伍

#### 乐马辽（乐进+马超+张辽）
- **定位**: 快攻处理队
- **适合**: 处理低战力目标

#### 反击薪火
- **定位**: 经典持久阵容
- **核心**: 驱散机制压制负面输出，高坦度克制追击流
- **弱势**: 无特定防御指令时易被左田孙压制

#### 南蛮队（孟获+祝融夫人+木鹿大王）
- **定位**: S13南蛮体系全攻核心
- **核心**: 木鹿大王三南蛮开局18%全队减伤
- **变体**: 可配合SP诸葛的薪火枪体系

#### 桃园队
- **定位**: S13文艺复兴，老牌强队重回主流

### S13共存推荐思路

**高红度玩家(6队共存)**:
1. 惇曹异（核心输出）
2. 泰飞延（补惇曹异短板）
3. 赵甘姜 或 乐马辽（灵活补位）
4. 左田孙（反制）
5. 百爆周瑜（亲卫营，压制快攻）
6. 其他针对性队伍

**中低红度玩家**:
1. 泰飞延（低配魏延主打机制克制）
2. 反击薪火（持久）
3. 左田孙（平民核心反制）
4. 根据区服环境调整

> 共存不是定式，适合自身情况和区服环境的共存才是好共存。

## 配队原则

1. **三角定位**：防御+输出+治疗/辅助
2. **战法配合**：武将战法之间需形成联动
3. **根据场景配队**：进攻/防守/扫荡用不同阵容
4. **免费调整**：新手期武将置换和战法重置免费，多尝试
5. **集中培养**：优先培养主力一队到满级(50级)
6. **考虑兵种**：不同武将可能适配不同兵种

## 开荒期配队建议

- 第一队(主力)：集中资源培养，经验书优先
- 第二队：放进练兵所训练，用于打低级地
- 主力队无体力时，用二队打地
- 新手期结束后(48小时)开荒队强度下降，需要调整阵容

## 多队共存

- S1赛季推荐5套共存阵容方案
- 随着君王殿升级可上阵更多队伍
- 不同队伍承担不同任务(进攻/防守/开荒)

### 玩家阵容与S13 meta对照
- **部队二(祝融+孟获+诸葛亮SP)**: 可考虑替换SP诸葛为木鹿大王，组成S13版南蛮队，触发18%全队减伤
- **部队四(陆逊+陆抗+孙权)**: 若对手大量惇曹异，SP诸葛移出南蛮后陆抗/陆逊生存空间被压缩
- **左田孙方向**: 玩家拥有孙权，可考虑配左慈+田丰组成平民反制队
